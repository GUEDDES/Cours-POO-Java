## 📚 À propos de ce cours

Ce cours est conçu pour les étudiants souhaitant **maîtriser la Programmation Orientée Objet** en utilisant Java. Il couvre progressivement tous les concepts fondamentaux jusqu'aux notions avancées.

### 🎓 Objectifs pédagogiques

- ✅ Comprendre les principes fondamentaux de la POO
- ✅ Maîtriser la syntaxe Java et ses particularités
- ✅ Apprendre à modéliser des problèmes réels en objets
- ✅ Développer des applications Java robustes et maintenables
- ✅ Pratiquer avec des exercices concrets et progressifs

### 📊 Contenu du Dépôt

- **12 sections complètes** avec théorie détaillée
- **3 Travaux Dirigés (TDs)** avec énoncés et corrections
- **9 exemples de code** fonctionnels et commentés
- **10 exercices** avec solutions complètes
- **3 diagrammes UML** (PlantUML)
- **Documentation complète** (README, CONTRIBUTING, LICENSE, SCREENSHOTS)

## 📚 Structure du Cours

### 🟢 **Section 1 : Introduction au Développement Logiciel**
📂 [`01-Introduction/`](01-Introduction/)

- Cycle de vie d'un logiciel
- Méthodologies de développement
- Qualité logicielle et bonnes pratiques
- **2 exercices** avec solutions détaillées

---

### 🔵 **Section 2 : Le Paradigme Orienté Objet**
📂 [`02-Paradigme-Objet/`](02-Paradigme-Objet/)

- Qu'est-ce qu'un objet ?
- Classes, attributs et méthodes
- Modélisation orientée objet
- **2 exercices** de modélisation

---

### 🟡 **Section 3 : Java - Les Fondamentaux**
📂 [`03-Java-Bases/`](03-Java-Bases/)

- Installation et JVM
- Premier programme (HelloWorld)
- Types primitifs et variables
- Chaînes de caractères (String)
- Tableaux (1D et 2D)
- **3 exemples de code** : HelloWorld, Calculatrice, GestionTableaux

### 🟠 **Section 4 : Classes et Objets en Java**
📂 [`04-Classes-Objets/`](04-Classes-Objets/)

- Définir une classe

- Le mot-clé `this` et chaînage
- Garbage Collector

- **2 exercices** : Classe Étudiant, Catalogue & Contrat d'Égalité (avec solutions)

---

### 🟣 **Section 5 : Éléments Statiques**
📂 [`05-Elements-Statiques/`](05-Elements-Statiques/)

- Membres statiques (`static`)
- Constantes (`final`)

- Classes utilitaires
- **1 exemple** : Calculatrice (classe utilitaire complète)
- **1 exercice** : MathPlus (avec solution)

---

### 🔴 **Section 6 : Relations entre Classes**
📂 [`06-Relations-Classes/`](06-Relations-Classes/)

- **Composition** (relation forte)
- **Agrégation** (relation faible)

- **2 exemples** : VoitureMoteur, UniversiteEtudiant
- **1 exercice** : Bibliothèque (avec solution)
- **📊 Diagramme UML** : Composition vs Agrégation

---

### ⚫ **Section 7 : Packages (Paquetages)**
📂 [`07-Packages/`](07-Packages/)

- Organisation en packages
- Import (spécifique, wildcard, nom complet)
- Conventions de nommage
- Résolution des conflits
- **Exemple complet** : Système de bibliothèque multi-packages

---

### 🟢 **Section 8 : Encapsulation**
📂 [`08-Encapsulation/`](08-Encapsulation/)

- Modificateurs d'accès (private, public, protected, default)
- Getters et Setters
- Validation dans les setters
- Principe du moindre privilège
- **Exemple** : Produit E-commerce avec validation

---

### 🔵 **Section 9 : Héritage**
📂 [`09-Heritage/`](09-Heritage/)

- Concept d'héritage (`extends`)
- Constructeurs et `super`
- Redéfinition de méthodes (`@Override`)
- Modificateur `final`
- **1 exemple** : AnimalHierarchie (Chien, Chat, Oiseau)
- **1 exercice** : Hiérarchie Véhicules (avec solution)
- **📊 Diagramme UML** : Hiérarchie Animal

---

### 🟡 **Section 10 : Polymorphisme**
📂 [`10-Polymorphisme/`](10-Polymorphisme/)

- Polymorphisme et liaison dynamique
- Classes abstraites
- Interfaces multiples
- Casting (upcast/downcast)
- Opérateur `instanceof`
- **1 exemple** : SystemePaiement (CarteBancaire, PayPal, Especes)
- **2 exercices** : Formes Géométriques, Moteur de Facturation & Remises Polymorphes (avec solutions)
- **📊 Diagramme UML** : Polymorphisme avec classes abstraites et interfaces

---

### 🟠 **Section 11 : Interfaces Fonctionnelles**
📂 [`11-Interfaces-Fonctionnelles/`](11-Interfaces-Fonctionnelles/)

- Expressions lambda
- Predicate, Function, Consumer, Supplier, BinaryOperator
- Streams et opérations (map, filter, reduce)
- Programmation fonctionnelle en Java
- **Exemple complet** : Gestion d'étudiants avec Streams

---

### 🔴 **Section 12 : Exceptions**
📂 [`12-Exceptions/`](12-Exceptions/)

- Gestion des erreurs avec try-catch-finally
- Lancer des exceptions (`throw`)
- Déclarer des exceptions (`throws`)
- Exceptions vérifiées vs non vérifiées
- Créer des exceptions personnalisées
- Transactions et intégrité des données
- **1 exemple** : GestionFichiers avec exceptions personnalisées
- **2 exercices** : Comptes Bancaires, Système de Transactions & Audit (avec solutions)

## 🚀 Comment utiliser ce cours ?

### 📚 Pour les débutants

1. **Suivez l'ordre** : Les sections sont progressives
2. **Lisez le cours** : Chaque section contient un `README.md` détaillé
3. **Étudiez les exemples** : Analysez le code dans le dossier `exemples/`
4. **Faites les TDs** : 👉 **[Commencer par le TD1](TDs/TD1-Fondements/)**
5. **Pratiquez** : Faites les exercices AVANT de regarder les solutions
6. **Expérimentez** : Modifiez le code et observez les résultats

### 🏃 Pour les développeurs expérimentés

- Utilisez le sommaire pour naviguer directement vers les concepts qui vous intéressent
- Consultez les **[TDs](TDs/)** pour évaluer rapidement vos connaissances
- Consultez les diagrammes UML pour une vue d'ensemble
- Contribuez en proposant de nouveaux exemples ou exercices !
