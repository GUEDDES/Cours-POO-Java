# Sorties Texte des Exemples - Section 3

## HelloWorld.java

```
$ javac HelloWorld.java
$ java HelloWorld
Hello, World!
Bienvenue dans le monde de Java !
```

## CalculatriceSimple.java

```
$ javac CalculatriceSimple.java
$ java CalculatriceSimple
=== CALCULATRICE SIMPLE ===

Nombre 1 : 10
Nombre 2 : 5

Résultats :
10 + 5 = 15
10 - 5 = 5
10 * 5 = 50
10 / 5 = 2.0
```
